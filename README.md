# Global Memory Representation
This project is a small-scale exploratory text analysis of how wartime atrocities associated with Germany and Japan may be framed differently through language in museum and educational narratives.

## Research Question
How do institutions use language to frame historical atrocities, particularly in terms of responsibility, morality, suffering, and recovery?

## Project Goal
The goal of this project is to examine how language reflects different approaches to historical memory, responsibility, and interpretation.

## Data Sources
- Short museum-style and educational narrative texts
- Comparative Germany and Japan case texts stored in the `data` folder

## Method
This project uses Python-based keyword frequency analysis to compare how German and Japanese narratives emphasize:
- responsibility and accountability
- victim and moral framing
- war, suffering, peace, and recovery

## Results
The analysis shows clear differences in narrative framing.

In the German text, responsibility-related language appears prominently. Terms such as “responsibility,” “crime,” “genocide,” “regime,” “state,” and “persecution” appear frequently, suggesting a stronger focus on institutional accountability and structured wrongdoing.

In the Japanese text, war- and recovery-related language appears more frequently. Terms such as “war,” “peace,” “tragedy,” “loss,” “suffering,” and “recovery” appear prominently, suggesting a stronger focus on human consequences and post-war reflection.

## Quantitative Summary
Germany shows:
- responsibility/accountability language: 11
- victim/moral framing language: 5
- war/suffering/recovery language: 0

Japan shows:
- responsibility/accountability language: 4
- victim/moral framing language: 0
- war/suffering/recovery language: 16

## Interpretation
These findings suggest that German narratives tend to frame atrocities through institutional accountability and moral responsibility, whereas Japanese narratives place greater emphasis on war, suffering, peace, and recovery.

This contrast highlights how language shapes collective memory and influences how historical responsibility is understood.

## Limitations
This is a small-scale exploratory project based on limited text samples and simple keyword frequency analysis. The results should therefore be interpreted cautiously.
